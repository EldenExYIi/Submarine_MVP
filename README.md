# 海底探险：泡泡弹潜艇 MVP

一个面向 6 岁以上儿童和家庭场景的本地 Web 体感游戏 MVP。玩家通过摄像头进行体感控制：头部移动控制潜艇位置，左右手控制两条机械臂，挥手发射泡泡弹清除海洋障碍物。

项目当前优先验证单人核心玩法、摄像头接入、姿态识别、双机械臂控制、泡泡弹射击、障碍物反馈和半透明摄像头背景。游戏不包含分数、生命值、失败、扣分或淘汰机制。

## 功能概览

- 摄像头输入和半透明镜像背景
- MediaPipe Pose 姿态识别
- 头部控制潜艇二维移动
- 左右手分别控制左右机械臂
- 挥手发射泡泡弹
- 泡泡弹命中障碍物后触发泡泡/星星反馈
- 障碍物碰到潜艇后触发摇晃/冒泡反馈
- 摄像头不可用时自动进入鼠标演示模式

## 运行项目

本项目是静态 Web 项目，不需要安装 npm 依赖。

在项目目录启动本地服务器：

```bash
cd /...
python3 -m http.server 5173
```

然后在浏览器打开：

```text
http://localhost:5173
```

点击“开始游戏”，并允许摄像头权限。

## 停止项目

在启动服务器的终端里按：

```text
Ctrl + C
```

看到 `Keyboard interrupt received, exiting.` 就表示服务器已停止。

## 注意事项

- 首次运行需要联网加载 MediaPipe 的浏览器端模块和姿态识别模型。
- 请使用普通浏览器打开并允许摄像头权限；部分内置预览浏览器可能会拒绝摄像头。
- 如果看不到最新改动，可以强制刷新：

```text
Cmd + Shift + R
```

- 如果摄像头权限被拒绝，游戏会进入鼠标演示模式：移动鼠标控制潜艇，点击发射泡泡弹。
