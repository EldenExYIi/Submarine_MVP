# 海底探险：泡泡弹潜艇 MVP

一个面向 6 岁以上儿童和家庭场景的本地 Web 体感游戏 MVP。支持 1-4 名玩家通过摄像头进行体感控制：头部移动控制各自潜艇位置，左右手控制两条机械臂，手从内向外快速摆动时会发射泡泡弹，清除海洋障碍物。

项目当前优先验证本地 1-4 人核心玩法、摄像头接入、姿态识别、双机械臂控制、泡泡弹射击、障碍物反馈和潜艇舷窗头像。游戏不包含分数、生命值、失败、扣分或淘汰机制。

## 功能概览

- 摄像头输入；实时画面只裁剪显示在潜艇舷窗中
- MediaPipe Pose 姿态识别，最多识别 4 名玩家
- 每名玩家用头部控制自己的潜艇二维移动
- 每名玩家用左右手分别控制自己的左右机械臂
- 玩家 1-4 使用不同潜艇颜色和编号
- 手从内向外快速摆动时发射泡泡弹
- 部分障碍物会轻微朝玩家方向漂移
- 泡泡弹命中障碍物后触发泡泡/星星反馈
- 障碍物碰到潜艇后触发摇晃/冒泡反馈
- 摄像头不可用时自动进入鼠标演示模式

## 运行项目

本项目是静态 Web 项目，不需要安装 npm 依赖，也不需要启动本地服务器。

直接用浏览器打开项目里的 `index.html`：

```text
/Users/exyii/Documents/Youdoo/Submarine/index.html
```

也可以在 Finder 中双击 `index.html`，或在浏览器里选择“打开文件”。

进入页面后点击“开始游戏”，并允许摄像头权限。

## 结束项目

直接关闭浏览器标签页或窗口即可。

如果之前手动启动过本地服务器，可以在对应终端里按：

```text
Ctrl + C
```

看到 `Keyboard interrupt received, exiting.` 就表示服务器已停止。

## 注意事项

- 首次运行需要联网加载 MediaPipe 的浏览器端模块和姿态识别模型。
- 请优先使用 Chrome、Edge 或 Safari 等普通浏览器打开并允许摄像头权限；部分内置预览浏览器可能会拒绝摄像头。
- 如果某个浏览器不允许 `file://` 页面使用摄像头，可以换用 Chrome，或临时用本地服务器方式打开。
- 按 `M` 可以切换隐藏的四人模拟测试模式，用于单人检查 4 艘潜艇、颜色编号、碰撞和性能。
- 按 `V` 可以切换隐藏的纵向调试模式：潜艇按当前玩家人数横向分布，单人居中，双人在 1/3 和 2/3 处，只随头部纵坐标上下移动。
- 如果看不到最新改动，可以强制刷新：

```text
Cmd + Shift + R
```

- 如果摄像头权限被拒绝，游戏会进入鼠标演示模式：移动鼠标控制潜艇，快速移动鼠标触发泡泡弹。
